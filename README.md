# Atividade prática — Página Web com HTML, CSS e JavaScript

**Disciplina:** Desenvolvimento de Aplicações para Internet

Atividade prática referente à matéria **Desenvolvimento de Aplicações para Internet**, utilizando HTML, CSS e JavaScript.

## Regras utilizadas

- Criar uma pasta para o projeto.
- Utilizar arquivos separados: `index.html`, `style.css` e `script.js`.
- Criar uma interface com os campos necessários para a regra escolhida.
- Utilizar pelo menos uma função JavaScript criada pelo aluno.
- Utilizar variáveis para armazenar os dados informados.
- Utilizar `if/else` quando a regra exigir tomada de decisão.
- Exibir o resultado da operação na própria página.
- Validar campos vazios ou valores inválidos.
- Utilizar objeto ou array quando fizer sentido para organizar os dados.
- Testar a aplicação no navegador antes da entrega.

## Regra escolhida

**Classificação por idade:** receber a idade e classificar a pessoa por faixa etária.
